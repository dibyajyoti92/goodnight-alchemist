# Project notes

One file per repo, named `<repo-slug>.md`, sitting next to this one. The master
agent reads it before planning and appends to it whenever the night teaches it
something. This is what makes the second overnight run in a repo smarter than
the first — the traps stop being rediscovered at 3am.

Keep them out of version control if they name clients, project ids or internal
paths. Nothing here needs to be shared to work.

## Template

```md
# <repo> traps (read before planning)

## Git / deploy
- branch to build from, who else writes here, what "published" means, how to prove it

## Verify commands
- typecheck / tests / build / lint, and any checklist doc

## Local run
- dev server command and port, auth bypass, seeding keys, fixture data

## Traps
- one line each, learned the hard way

## Costs
- what spends money or credits here, and the cap
```

## Worked example

```md
# acme-dashboard traps (read before planning)

Repo `acme/dashboard`, deployed on Vercel from `main`, Supabase backend.

## Git / deploy
- `main` auto-deploys on push; a pushed branch ships nothing.
- Push is not publish. After pushing, wait for the deployment to report ready,
  then fetch the live bundle and grep for a marker only the new code has.
- A committed `.sql` file is a proposal, not a migration — migrations are
  applied by the CLI, and nothing applies them for you. Verify afterwards that
  the object exists *and* that `anon` cannot touch it.

## Verify commands
- `pnpm typecheck` · `pnpm test` · `pnpm build` — all three before any push.

## Local run
- `pnpm dev` on :3000. `?e2e=1` short-circuits the auth guard in dev builds
  only; without it every signed-in screen redirects to the login page.
- Seed data lives in `localStorage` under `acme.dev.store` — see
  `src/lib/dev-seed.ts` for the shape.

## Traps
- The admin route must sit outside the `(app)` layout group: an admin belongs
  to no team, so the layout guard bounces them into onboarding.
- `routes.gen.ts` is regenerated by the dev server with line-ending-only
  changes. Restore it, don't commit it.
- Rate limits are real: the upstream API allows ~200 lookups an hour, and
  cached figures older than 30 days must be deleted under its terms — but
  figures a human typed in must never be wiped by that rule.
- Never write test rows into the production database, even inside a rolled-back
  transaction. Use a throwaway tenant, or queue the test for the morning.

## Costs
- Preview deployments are free; the upstream API bills per 1,000 lookups.
  Cap: 5,000 lookups a night without asking.
```
